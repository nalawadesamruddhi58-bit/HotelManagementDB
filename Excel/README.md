# Hotel Management – Excel Data Analysis

## Project Overview
This project focuses on analyzing hotel management data using Microsoft Excel. It demonstrates practical data cleaning, data preparation, and Excel formula skills using a hotel management dataset.

## Tools Used
- Microsoft Excel
- MySQL (for the source database)

## Dataset
The project uses six tables:
- Guests
- Rooms
- Bookings
- Payments
- Services
- Booking_Services

## Data Preparation
- Imported data from MySQL into Excel.
- Created separate copies of the original datasets for cleaning.
- Handled missing values.
- Checked for duplicate records.
- Prepared clean datasets for analysis.

## Excel Skills Practiced
- SUM, COUNT, AVERAGE
- COUNTIF, SUMIF, AVERAGEIF
- COUNTIFS, SUMIFS
- IF, AND, OR, IFERROR
- XLOOKUP, VLOOKUP

## Project Progress
This project is being developed step by step. Business analysis, Pivot Tables, Charts, and Dashboards will be added in future updates.
