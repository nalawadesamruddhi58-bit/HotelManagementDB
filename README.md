# Hotel Management Database Project

## Project Overview
This project uses MySQL to create and manage a hotel management database. It stores information about guests, rooms, bookings, payments, and hotel services.

## Database Tables
- **Guests:** Stores guest details.
- **Rooms:** Stores room information, prices, and availability.
- **Bookings:** Stores guest booking details.
- **Payments:** Stores payment information.
- **Services:** Stores hotel services and their prices.
- **Booking_Services:** Connects bookings with hotel services.

## SQL Concepts Used
- CREATE DATABASE and CREATE TABLE
- INSERT, UPDATE, and ALTER TABLE
- SELECT and filtering
- Aggregate functions
- GROUP BY and HAVING
- INNER JOIN, LEFT JOIN, and RIGHT JOIN
- ORDER BY and LIMIT
- CASE, UNION ALL, and NULL handling

## Tools Used
- MySQL
- MySQL Workbench
- GitHub

## Project Purpose
The purpose of this project is to practice SQL queries and analyze hotel-related data, including room availability, bookings, payments, and services.

## Note
This project uses sample data for learning and practice.
